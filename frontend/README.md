# TruthTrace 现实档案调查局

校园兼职押金纠纷调查工作台的可交互前端。保留软木证据墙与纸质卷宗的视觉，并提供一段可以亲手推进的模拟调查。

## 从空白案件开始

网站根地址现在打开「我的案件」，首次进入不会显示任何分析结果。

1. 点击「创建案件」，在同一页填写案件名称并选择材料；支持图片、PDF、TXT、MD，每份不超过 15 MB，最多 8 份，可移除并预览。
2. 比赛演示时点击「导入示例材料」，会出现与示例分析相对应的四份原始文本。点击「开始整理」，经过简短、明确标记的模拟分析过程。
3. 完成页显示材料、人物和疑点的示例统计，点击「进入调查工作台」，继续使用原有关系图、证据对照和沉浸展示。

选择自己的文件会进入本地材料工作台，展示真实文件预览，人物和关联保持待分析；不会把校园押金示例结论套用到这些文件。当前尚未连接 OCR 和模型接口。

整理过程中可返回修改材料，已选文件不丢失。案件首页可继续最近一次调查；刷新后本地文件需重新选择，示例调查进度可以恢复。左上角品牌入口及侧栏「新建案件」可返回创建流程。旧的 `/#graph-demo` 和 `/#center` 仍保留为示例工作台快捷入口。

咪探长在工作台中只保留一句重点及一个操作按钮，按钮直接打开材料或核查操作；调查中心仅保留右栏助手，移除了重复的底部提示。

## 本地运行

需要 Node.js 22 或更新版本，无需安装依赖。

```sh
npm start
```

打开 http://127.0.0.1:4173 。调查中心可直接通过 http://127.0.0.1:4173/#center 进入。页面使用 ES Modules，请通过本地服务器预览。

```sh
npm run check
npm test
```

## 调查中心 推荐比赛演示

点击左侧第一个「调查中心」，再点击右上角「全屏展示」，可把专题页铺满浏览器页面；点击「退出展示」或按 Esc 返回。

三栏各有固定用途：左侧选择证据与人物，中间上半区查看当前资料、下半区推进核查，右侧显示助手提示及案件内关联检索。材料与进度共用证据墙的数据。

1. 在中间材料区摘录 E-02 的退款承诺，在左侧选择 E-03 并摘录到账时间。
2. 在下方核查记录中提交阶段判断。
3. 点击领取 E-05，在同一页摘录完整回单，再提交复核结论。
4. 可在右侧输入 `R202610310017`，检索并切换 E-03、E-05 的关联记录。

以上主流程无需打开卷宗弹窗。「完整原文」和「线索簿」仍可用于深入阅读和导出。

## 关系图沉浸演示

在线索关系图右上角点击「沉浸全屏」，案件名称、统计、关系图和重点发现会一起进入展示模式，无需滚动整个页面。支持时调用浏览器原生 Fullscreen API；环境不允许时，仍保持铺满浏览器页面的沉浸布局。点击「退出全屏」或按 Esc 返回。

比赛可直接打开 `/#graph-demo`，自动进入沉浸布局；原生浏览器全屏需要一次用户点击。

点击右侧第一张重点发现，会自动定位并高亮 E-02、E-03 及关联线；取得 E-05 后也会同步高亮回单。图上的定位条提供「打开证据对照」和「显示全部」。第二张卡片对应 E-01、E-04，保留待核实关系的虚线。定位按照当前卡片位置计算，支持拖动后的再次定位。

助手统一名为 **Synapse · 咪探长**。左上角为咪探长举放大镜探头的头像；底部猫咪支持悬停、点击、触屏轻触和 Enter / Space 反馈，并遵守减少动态效果偏好。

## 卷宗调查流程

1. 点击小猫旁的 AI 助手，或右侧第一个调查任务。
2. 翻阅 E-02 的聊天记录，摘录退款承诺；再翻到 E-03，摘录到账时间。
3. 进入证据对照台，选择材料能够支持的阶段判断。无依据的指控不会推进任务。
4. 拆封 E-05 完整退款回单，摘录交易对应关系，再完成第二轮复核。
5. 在调查笔记中写下自己的观察，导出带来源编号及待查事项的 Markdown 文件。

进度、线索和笔记仅保存在当前浏览器。线索簿里可重新开始演示。

## 已实现的交互

- 调查中心三栏同页工作流、线索目录筛选、人物资料切换、案件内关联检索与整页展示。
- 点击人物与证据卡查看档案；卷宗可切换材料、摘录线索、返回来源。
- 画布平移、纸卡拖动、动态连线、缩放及全屏查看。
- 事件时间线、证据搜索、人物档案与调查任务视图。
- 两轮证据判断、补证解锁、新证据同步到证据墙与时间线。
- 线索簿、个人观察自动保存、调查笔记导出、演示重置。
- AI 助手按当前进度给出有来源的固定演示提示。
- 本地图片、PDF、文本选择或拖放，加入档案后可预览。

上传文件不会发送到服务器；当前页面仅预览，不进行 OCR 或 AI 分析，刷新后需要重新选择。AI 助手尚未连接大模型。案件通关规则属于演示逻辑，不能用于自动判断真实案件。

案件人物、证据内容与发现均为虚构演示信息。生成的校园和学生图片仅用于示意；页面中的聊天、招聘公告和付款凭证缩略图由 HTML/CSS 构成。
