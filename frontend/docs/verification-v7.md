# v0.7.0 首次使用流程验证

2026-11-01，通过本地 localhost 浏览器预览验证，未重置线上原有调查进度。

- 首次打开根地址显示空白案件首页；原工作台隐藏，没有人物、疑点或分析结果提前出现。
- 创建页未填写名称、未选择文件时，开始整理按钮不可用。
- 导入四份示例材料后，可查看与分析数据对应的原文，按钮开放；开始整理进入三个阶段的模拟过渡，工作台仍保持隐藏。
- 整理途中返回修改，案件名称及四份文件保留；再次整理后显示完成页，点击入口才进入原关系图。
- 从咪探长的提示条点击操作，直接进入 E-02 原文，没有助手说明弹窗。
- 调查中心助手为一句重点、一个按钮，没有长段说明，也没有重复底部提示。
- 通过系统文件选择器导入测试文本和图片两份实际文件。文本显示原文、图片载入成功；移除图片后数量及预览同步更新。
- 自己的材料进入本地整理及材料工作台，显示实际文件和待解析状态，未显示校园押金示例的分析结论。
- 刷新后，首页保留本地案件名称与数量。继续时提示重新选择文件，旧 object URL 未被错误恢复，整理按钮重新禁用。
- 390×844 窄屏下，创建页没有横向溢出，名称输入框与主要操作可见；测试结束恢复默认预览尺寸。

新增批量文件校验、数量 / 大小边界、示例原文引用一致性三项测试；连同原有五项调查测试共八项通过。
