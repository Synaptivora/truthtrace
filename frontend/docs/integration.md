# 前端交互与联调说明

## 当前数据与运行方式

当前所有案件内容位于 `dist/case-data.js`，包括 EVIDENCE、PEOPLE、TIMELINE 和从材料中摘录的 CLAIMS。浏览器交互位于 `script.js`，判断规则与报告生成位于 `investigation.js`。没有数据库、API 密钥或大模型调用。

## 新建案件与分析入口

首次使用流程在 `dist/onboarding.js` 的 `initEntryFlow` 中。`addFiles` 负责文件校验、原文预览及移除；`analyze` 负责导入后的整理状态，目前使用短计时器模拟三个阶段。这里是接入 A 上传 / 解析任务与 B 分析进度的位置，正式接入时应由接口的实际任务状态驱动进度，不保留假计时器。

`createSampleFiles` 直接从现有 EVIDENCE 生成四份初始示例文本，确保演示分析有对应的导入原文。示例流程完成后通过 `onDemoReady` 回调进入原工作台。真实文件走本地材料预览，不调用该回调，不加载任何预设人物、矛盾或关系图。

当前案件名称、模式与材料数量另存于 `truthtrace.active-case.v1`，仅用于首页继续入口。原始文件、文件内容和 object URL 均不进入 localStorage；刷新后需要重新选择本地文件。未来替换为后端案件 ID 和受权限控制的文件地址。

UI 已区分示例分析与未解析的本地文件，接入真实结果时应维持这一区分。所有人物与矛盾必须引用实际已导入材料，不能把示例结果用于任意上传。

工作台助手提示集中在 `assistantCue`，一条简短重点对应一个操作。图上按钮直接打开材料 / 对照，调查中心保留同页操作，不再弹出助手说明卷宗。

调查中心由 `renderCenter` 及其资料、核查、检索子函数渲染，沿用相同状态与证据编号；样式位于 `center.css`。左侧选择不会打开弹窗，关键原文、线索摘录与判断都在专题页内完成。右侧检索只匹配当前已载入材料的编号、名称、摘要及记录字段，不查询外部系统，也不展示未解锁的 E-05。

材料的 `id` 是原文、线索、人物与时间线共同使用的引用键，不能在各模块独立生成不同版本。每条线索通过 `sourceId` 返回对应材料。

## 模拟调查的状态

| 字段 | 含义 |
| --- | --- |
| read | 已翻阅的证据编号 |
| clues | 用户主动摘录的线索编号 |
| stage | 0 未判断，1 阶段判断后待补证，2 完成退款时间复核 |
| extra | E-05 是否加入档案 |
| note | 用户自己填写的观察 |
| positions | 纸卡在 1100 × 600 画布中的位置 |
| checks | 主体身份补证安排的勾选状态，不代表事实已核实 |

状态存储在当前浏览器的 `truthtrace.case-001.investigation.v1` 中；本地上传的文件不进入这个存储，仅在当前页面预览。

## A 需要对接的部分

用上传接口替换 `importFiles` 中的本地预览逻辑。前端应收到材料编号、文件类型、原始文件地址、解析内容及来源位置。下列原文定位字段是联调草案，尚未与队友确定，不是现有接口：

```json
{
  "id": "E-01",
  "title": "材料名称",
  "kind": "image",
  "source": { "url": "/evidence/E-01", "page": 1, "bbox": [0.1, 0.2, 0.8, 0.3] }
}
```

真实材料应显示原图、PDF 页或原文片段。演示用的 HTML 聊天、公告和回单不能替代真实上传材料。

## B 需要对接的部分

约定人物、事件、说法、矛盾与补证建议的 JSON 结构。每个分析结果必须引用现有证据编号，并区分材料记载、人物说法和已核查内容。格式验证不能替代事实核验。

当前 `assessVerdict` 是专为虚构案件设计的两轮演示规则。接入真实案件时，应关闭固定答案与补证解锁条件，用 B 返回的可追溯结果和用户主动核验替换。不得把一个演示答案用于判定任意上传文件。

当前 AI 助手是按演示进度切换的固定提示。接入模型时，替换 `assistantCue` 的内容来源，保留证据引用和未解决问题；不应让模型直接输出无来源的定性。

调查中心右栏的固定引导由 `centerGuide` 生成，同样需要随真实分析接口替换。案件内检索可在正式接口确定后改成后端查询，但必须保留结果来源和材料编号。

## 演示与测试

`npm test` 检查缺失依据不能推进、无依据指控不会通过、复核依赖补充回单、进度恢复清理无效引用，以及导出笔记保留来源和未解决事项。

前端完整演示路径写在 README；线索簿可重置本地演示进度。上传、拖动、档案翻阅、判断及下载可以通过浏览器实际操作验证。
