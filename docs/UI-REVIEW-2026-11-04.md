## 可复现验证

使用生产构建和临时虚构材料；不调用真实模型或渠道。命令从仓库根运行：

```text
npm test
npm run typecheck
npm run lint
npm run build
node scripts/conversation-smoke.mjs
node src/components/truthtrace/case-search/browser-smoke.mjs
npm run test:investigator
npm run test:browser
```

产品脚本覆盖搜索和历史版本定位、退出高亮、历史读取失败保留引文、承诺筛选、时间线、报告预览 Esc/焦点返回和真实下载；会话脚本覆盖刷新、内联编辑、确认删除与跨案隔离。产品截图默认保存在 `artifacts/product-ui/`，会话截图在 `artifacts/conversation/`；这些是本地可再生验证产物，不含用户材料。

桌面与 390px 窄屏均需查看截图并检查页面无横向溢出；不能只凭构建成功宣称 UI 完成。真实模型质量、人工事实核查和公网部署限制仍遵循 RELEASE-CANDIDATE.md。
