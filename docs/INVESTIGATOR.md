# 本地自主调查

## 启动

使用 Node.js 24（本机验证版本 24.14.0），在仓库根目录执行：

```powershell
npm ci
npm run dev:local
```

它启动仅监听 `127.0.0.1` 的 Next.js 和独立调查 Worker。生产模式先 `npm run build`，再 `npm run start:local`。也可分别运行 `npm run dev` 与 `npm run worker`。关闭浏览器不会终止 Worker；停止电脑或进程后，重启将回收过期的 30 秒租约并从已完成 Skill 继续。

页面“设置”→选择供应商→填写连接→“测试并加密保存连接”。可选默认共享，或只覆盖对话、分析、自主调查。保存会调用模型验证文本和工具传输。没有工具能力的连接不能启动自主调查。图片能力目前显示未测试，使用前需自行确认模型支持视觉。

Windows 上 AES-GCM 加密连接文件，随机主密钥由当前操作系统用户的 DPAPI 保护。密钥不保存于浏览器、报告和任务事件。其他系统暂使用 `AGENT_*` / `AI_*` 环境变量；不可把 Windows 的 DPAPI 文件复制到另一用户后期待能够直接解密。

创建/打开真实案件→“自主调查”→输入目标→开始。页面显示调查步骤、主张、核查结果、人物候选、关系、时间线、潜在矛盾和补证建议。可以暂停、继续、取消、纳入新材料修订，以及导出 Markdown。

## 调查范围和用户决定

默认只处理本案导入材料。可选择已连接的微信、钉钉，填写会话 ID 和起止时间；Worker 只调用现有 `/source/extract` 的固定范围，不调用没有范围约束的全源同步，不替用户授权账号。此路径是确定性取数，Python 原有独立取数模型配置没有被更改。`INGESTION_SERVICE_URL` 必须指向已经配置的本地解析服务。

勾选视觉后，支持的数据 URI 原图才能进入模型；没有勾选不会发送像素。图像识别引文不宣称通过逐字校验，自动降为部分支持并提示人工核查。不具备坐标的图片仅定位整图，不编造 OCR 坐标。文本目前定位到稳定版本的字符区间；聊天消息 ID、PDF 页码坐标仍需解析器提供后才能接入。

人物只作为候选。用户可采纳、驳回、修改或标记待核实，并填写理由。运行中先暂停再提交；决定后重跑人物与后续阶段，保留旧报告和决定历史。用户意见与证据支持状态是不同字段，用户意见不会变成原始证据。

## 持久化与恢复

默认数据目录 `.truthtrace/`，可用 `TRUTHTRACE_DATA_DIR` 设置绝对目录。Next 与 Worker 必须指向同一目录。

- `cases.sqlite`：案件、不可覆盖的证据版本、任务、事件、报告版本。
- `originals/`：上传文件的原始字节，以 SHA-256 命名。
- `objects/`：解析后的材料内容，以哈希命名。
- `connection*.enc` / `master.dpapi`：本机加密连接及受 OS 保护的主密钥。

备份时停止两个进程，完整复制目录；不得只复制正在运行的 SQLite 主文件而遗漏 WAL。哈希用于去重与完整性，不代表来源真实性。旧页面里已经丢失的案件无法追溯恢复。

每案最多一个未结束任务。每任务默认 40 次模型调用、120 次工具调用、30 分钟主动执行；等待用户不计入。网络/限流/服务端临时失败最多重试两次，计入调用预算。达到预算暂停，修订目标会开启新的报告修订及预算。每一步写入检查点；中断的当前步骤可能重新请求模型，但已完成步骤不会重做。暂停或取消会拒绝迟到的提交。

当前报告可包含证据不足和未读取片段；没有发现反向材料不代表没有反向材料。引用检查验证来源存在、确切版本、已读取片段和逐字引文，语义复核仍属于模型辅助判断。

## Skill 与接口

八个 `skills/*/SKILL.md` 在 Worker 每个阶段真实加载，版本 1 写入步骤事件。主 Agent 共用已有模型传输协议；`runtime.ts` 中的工具注册表提供目录、搜索、读取、上下文和各阶段结构化提交。提交通过 Zod 和证据验证后才会推进步骤。未知工具不会执行。

新增接口：`/api/cases`、`/api/cases/:id`、`/api/cases/:id/evidence`、`/api/cases/:id/investigations`；`/api/investigations/:id` 及 `events`、`actions`、`decisions`、`report`。事件接口按 `after` 游标返回分页 JSON；页面每两秒刷新任务。报告可通过 `?revision=N` 读取旧版本。事件为执行记录，不包含模型隐藏推理。

## 验证与当前边界

```powershell
npm run test
npm run typecheck
npm run lint
npm run build
npm run test:investigator
```

浏览器测试启动隔离的临时 SQLite、生产服务、Worker 和虚构本地模型；覆盖八阶段完成、刷新、报告引用、桌面与 390px 窄屏。测试目录路径在完成时输出，截图位于 `artifacts/investigator/`。

真实渠道授权、真实供应商效果、扫描 PDF/OCR 尚需实际环境验证。当前调查不进行网络搜索、对外发送消息、自动账号授权或法律责任认定。既有短对话助手仍保留原来的引用规则；更严格的片段与主张校验应用于自主调查。没有在本变更中合并远端 PR #7/#8。
