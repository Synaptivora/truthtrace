# 数据与隐私边界
聊天、附件、OCR及分析结果可能包含个人信息。默认在本机存储；向配置的模型供应商发送文本或获授权图片前，应确认供应商及其数据政策。模型原文引用仅证明系统读到该内容，不证明外部事实真实。

- Interactive与调查读取当前材料；图片发送需要明确授权。结构化材料分析当前以文本为主，未读/截断/丢弃范围应展示。
- 本机会话和Python服务令牌用于访问控制，不等于磁盘全量加密。Windows连接密钥使用DPAPI，SQLite、原件和报告不能因此称为已加密。
- 审计事件只记录工具/状态/计数等元数据，不记录读出的完整原文或任意上游异常；案件本身仍保存证据。安装输出不直接发给浏览器，设备登录仅使用允许的官方URL。
- 导出报告会携带引文和人工备注；接收者可见这些内容。HTML导出禁脚本和外部资源，但分享前仍须人工检查隐私。
- 备份是另一份敏感数据，删除活动案件不自动删除历史备份；需单独治理保留期。Python归档有配额及保留清理，数据库、报告、会话删除能力以产品实际提供的操作为准，不承诺未实现的一键彻底删除。
- 评估使用完全虚构材料。真实模型评估必须显式配置，记录模型/版本/token/费用；未执行就标未验证。
