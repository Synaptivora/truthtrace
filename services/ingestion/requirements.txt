# 不要装任何 OCR 引擎：rapidocr / rapidocr-onnxruntime / onnxruntime /
# opencv-python / pytesseract / paddleocr。
#
# 截图一律当 kind="image" 交给 B 的视觉模型，A 不做本地 OCR。
# 理由见《A环节任务拆解.md》的 A5 小节（已决策不做），核心两条：
#   1) 视觉模型读中文聊天截图本来比 OCR 准；
#   2) 截图一旦 OCR 成 kind=chat，`validate.ts` 就会对引文强制逐字命中，
#      OCR 文本里中文间的空格会让整条分析链路 400。
#
# 注意：pip 装 onnxruntime 会顺带拉 numpy/opencv（约 +110MB），装了也没人用。
